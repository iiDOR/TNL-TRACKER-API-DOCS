# TNL API — Endpoints Used in TNL Tracker

> **Base URL:** `https://api.tamilnadulogistics.in`  
> **Auth:** `Authorization: Bearer <token>` (JWT, stored via Tauri credential store)  
> **Spec:** `openapi.json` (Swagger 2.0, auto-generated)

---

## GET /api/me/dashboard

**Tauri command:** `api_get_dashboard`  
**Description:** Main dashboard data for the logged-in rider

**Tags:** Me  

**Response:** OK

---

## GET /api/auth/profile

**Tauri command:** `api_get_profile`  
**Description:** Full profile of the authenticated user

**Tags:** Auth  

**Response:** OK

---

## PATCH /api/me/profile

**Tauri command:** `api_update_profile`  
**Description:** Update editable profile fields

**Tags:** Me  

**Request body fields:**
- `name`: any
- `tmpIngameName`: any
- `avatar`: any
